# Standard Latin and Ancient Greek Hunspell data

These files are the unmodified standard spelling profiles from the project's
v2.0.0 release. They are provided here as raw, commit-pinned source files for
downstream language-pack manifests.

Source: [v2.0.0 release](https://github.com/7k54t88hbw-collab/latin-dictionary-and-hyphenation-for-adobe-indesign/releases/tag/v2.0.0),
manual-install archive `Latin-and-Ancient-Greek-Dictionaries-for-Adobe-InDesign-2.0.0-Manual-Install.zip`,
SHA-256 `9fe68288e85f17672df40e4e22971ebad31937b41149acb9f1049d29d221385b`.

The spelling data is derived from the 2026-11-01 English Wiktionary dump and
is available under CC BY-SA 4.0. Attribution: Wiktionary contributors; the
release's provenance manifests identify source pages and revisions. The
standard profile is selected for each locale. The release also provides
macron-enforcing Latin and polytonic-enforcing Ancient Greek profiles; the
current one-pair-per-locale language-pack format cannot expose those alternate
profiles, so they are not included here.
